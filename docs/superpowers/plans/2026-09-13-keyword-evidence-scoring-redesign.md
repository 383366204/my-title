# 关键词证据、评分与结果分流优化计划

状态：分阶段实施中。2026-09-14 已接入统一指标解析与挖词筛选诊断；商品证据判断、双层决策改造、四组结果界面及离线重分析接口尚未实施。

## 1. 问题与目标

实测运行 2026-09-12-151052 查询 8 个词根，取得 105 行原始数据；离线复现中，102 行因固定词库未识别商品而低分，3 行命中本地拒绝规则，最终候选为零。增加采集页数和降低文字分门槛没有解决识别缺陷。

另有三个独立问题：多个指标解析器口径不同；机会分再次使用本地文字分的 35% 权重；采集成功但筛选为空被展示成采集无数据。

目标是增加合理候选覆盖和可解释性，不以全量通过为验收目标，不承诺选出的词一定有货源或盈利。

## 2. 判断架构

处理顺序：保存原始证据 → 结构化解析 → 商品与风险判断 → 市场评估 → 结果分流 → 货源验证。

每条候选独立保存以下结果，禁止加权抵消安全风险：

| 维度 | 输出 | 作用 |
| --- | --- | --- |
| 商品识别 | known / supported / uncertain / invalid | 词库未知不等于商品无效；supported 必须带证据 |
| 词根关联 | same_product / accessory / related / uncertain | 不能把词根形态无条件继承给所有关联词 |
| 品牌与其他风险 | clear / suspected / confirmed + reasons | 缺少命中不等于无风险，品牌疑似默认人工审核 |
| 市场表现 | 原始指标、区间、可用性、相对排序 | 仅支持市场判断，不证明产品身份和授权 |
| 决策 | 推荐选品 / 待复核 / 观察 / 排除 | 保存理由、规则版本、证据引用 |

具体商品形态和查询相关性由程序规则优先验证；歧义条目才调用模型。模型返回证据引用、商品名词、关系、解释及不确定状态，结果缓存。禁止仅凭模型置信度自动通过。

例如“充电宝超薄小巧便携”可以是同商品，“充电宝收纳包”是配件，“充电宝维修教程”不是货源商品。真实返回的搜索词不一定具备采购意图。

## 3. 指标解析先于调参

建立一个领域解析模块，由挖词门槛、生意参谋评分、关键词机会判断共同使用；废除各自的 parseFloat/取最大数字策略。

- 保存 raw、value/lower/upper、unit、status、trendRaw、trend、parserVersion。
- status 区分 exact、range、missing、ambiguous；合法 0 不等于缺失。
- 百分比内部统一为比率，展示转为百分数；数量的千、万单位逐端点解析。
- `1200 ~ 2500-10%` 应把人气区间与趋势拆开，不能把趋势混进数值。
- `10 ~ 500%` 等粘连文本没有 DOM 分段证据时标记 ambiguous，不猜测。
- 点击率超过 100% 不擅自截断或当作错误：保留平台字段含义与单位，待确认口径。
- 区间跨越门槛时进入待复核；缺失关键指标不通过重分配权重变成高分。
- hot、blue、blue_relaxed、时间周期、筛选条件、页面覆盖与采集时间始终保留。重评分不改变采集时间和来源。

## 4. 商品识别与风险

不再因为固定商品词库未命中而减 16 分并淘汰。已有商品化结果可作为证据，但只对匹配或明确同义的候选有效；排序变体、配件及跨类目词分别处理。

品牌检查结合词典、显式品牌字段和模型疑似标记，明确承认覆盖不完全。“觅光”“霍尼韦尔”等测试样本不得自动进入普通无品牌铺货；不自动删除品牌或拿普通商品冒充原品牌。合法品牌采购可以走人工授权与真实货源确认。

根级推荐类目只作为候选类目提示，不赋予每条关联词已确认类目。类目冲突进入复核。

## 5. 评分与决策

移除文字长度、修饰词丰富度对已有生意参谋证据的硬门槛，并移除机会分中对应的 35% 再次扣分。旧本地评分可以保留作未查词的查询优先级，不再作为市场表现。

首版优先展示指标与理由，不急于重新拼一个通用 100 分公式。确有排序需要时，只在同查询模式、周期和可比类目内进行市场排序；小样本和区间不确定性必须显示，不能把每批最高分当成跨批次绝对好词。

- 推荐选品：商品明确、关联可信、无待处理风险且市场证据支持；仅允许进入货源研究。
- 待复核：词库未知但有实体商品证据、区间跨阈值、疑似品牌、类目冲突等。
- 观察：数据可解析但市场表现偏弱；保留记录并受 30 天复查约束。
- 排除：明确违规或非商品意图等有证据的原因；保留审计记录，不静默删除。

严格/均衡/探索控制研究候选的覆盖与复核分流，不改变单位解析、风险底线和铺货授权。不让“探索”变成自动放行。

## 6. 节点交互与诊断

在节点上展示：采集行数、唯一词数、推荐数、待复核数、观察数、排除数。分页重复记录与多词根来源合并，计数有明确分母。

节点主按钮打开同一个结果弹窗，按上述四组查看；每行展示原词、来源词根、商品判断、市场指标、风险、原因和下一步。人工确认记录依据与范围，不覆盖原始自动结论。

失败原因分开：平台不可用、真实空结果、全部观察/排除、全部待复核。后三种不显示“没查到关联词”；待复核引导人工筛词，真实平台问题提供打开 Chrome、重试等现有操作。

补充“用已有数据重新分析”操作：明确不会重新访问生意参谋，模型分析如有费用另行显示；不得把该操作伪装成重新采集。

货源阶段保存查询词、原始返回数、去重数、匹配过滤数、商品门槛结果和错误，避免再次遇到 0 商品却不知道过滤环节。

## 7. 实施顺序

1. 诊断与离线基线：固定 105 行快照及较早的 72 行样本，补充逐阶段原因计数，不改用户历史文件。
2. 指标标准化：统一解析契约和测试；旧原始快照离线重解析，缺乏原始值的旧数据标记不可恢复。
3. 商品与风险判断：传递根级证据、判断关联关系、疑似品牌分流，覆盖未知但具体的商品。
4. 双层评分改造：同时修改挖词门槛和机会分，确保未知商品不会在下一层再次被旧文字分淘汰。
5. 节点结果与货源诊断：结果四分组、原因展开、人工操作、重新分析接口；采用新评估版本，保持旧结果可追溯。
6. 离线对照和小批实测：先检查精度与漏选，再使用现有限流做最小必要的在线验证。不得自动铺货。

新分析写入独立评估 revision。若下游已有复核或产物，重分析后明确提示其依据旧版本；不自动重跑、覆盖或继续铺货。查询周期和 30 天冷却记录不因重评分而变化。

## 8. 验收条件

- 105 行全部有可追溯去向；行数与去重词数分开，不能为了凑通过数量而放宽安全要求。
- 人工标注的明确商品不再仅因词库未知而被排除；疑似品牌、配件和教程反例不能误放行。
- 百分比、区间、万单位、合法零、缺失、趋势粘连、超 100% 指标均有独立测试。
- 同样原始证据、解析版本和规则版本得到稳定结果；重评分不访问浏览器、不延长冷却。
- 原始采集成功且结果全待复核时，节点不显示“查询无数据”。
- 比较旧/新方案的漏选、误放行、待复核负担、类目多样性、模型调用量；不能只比较通过率。
- 当前未验证线上收益，不以测试通过宣称商业效果提升。
