# 灵感多属性查询

## 已实现

- 商品化提示词返回原词、商品核心和材质/场景/功能/人群属性。代码仅接受原词中已有的连续属性及商品核心，不杜撰新属性，不做字符截断。
- 原词与有效属性商品词分别查询 hot、blue，两种模式串行执行，复用既有平台访问控制。启动页默认每个查询模式三页，显式页数配置仍有效。
- 查询任务按规范化查询词和榜单去重，并保留原始商品词与灵感来源。
- 缓存按词及查询上下文匹配，记录模式、周期、页数及蓝海筛选条件。可复用同上下文三十天内的结果，不改写采集时间；另一榜单不会被误跳过。
- 同一候选词合并展示，sycmEvidenceRows 保存各路独立原始指标，不合计或平均不同查询的数据。
- 保存运行查询计划和逐词任务结果，词根结果可展开查询明细；日志显示查询序号、词、榜单及分页进度。
- 旧发现快照缺乏拆分字段时仅使用原词，不自动追加模型调用或改写历史快照。
